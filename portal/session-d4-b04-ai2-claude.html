    02 · Proyectos · Feature 01

    Donde el contexto vive.

    Un Proyecto en Claude.ai es un contenedor con instrucciones permanentes y archivos de referencia. Toda conversación dentro del Proyecto hereda ese contexto — no tienes que re-explicar quién eres ni qué cliente es.

    Para cada engagement LCG, crea un Proyecto con esta estructura:

    Campo
    Qué poner
    Nombre
    {Cliente} · {Tipo de proyecto} — ej. Aura · Excelencia Comercial
    Custom Instructions
    Tu rol (Consultor LCG), el cliente y vertical, los 5 indicadores principales del MEF, glosario de siglas internas del cliente, voz LCG ("respuestas estructuradas, sin marketing-speak").
    Project Knowledge
    Sube: contrato anonimizado, MEF aprobado, organigrama, Plan de Vuelo. Máximo ~50 archivos, 200MB total.
    Quién accede
    El Proyecto es personal. Para compartir contexto con el equipo, exporta los archivos a SharePoint y crea Proyectos paralelos con el mismo material.

    Plantilla LCG de Custom Instructions:

    // Pega esto en Custom Instructions y rellena los {...}

Eres mi copiloto en un proyecto LCG con {cliente}, vertical
{vertical}. Mi rol es {Consultor / Gerente}.

CONTEXTO DEL PROYECTO
- Tipo: {Excelencia Comercial / Lean 4.0 / Supply SCM}
- Etapa: {Análisis Exhaustivo / Diseño / Implementación}
- Indicadores MEF: {lista 3-5 KPIs principales}

VOZ Y FORMATO
- Respuestas estructuradas, sin marketing-speak ni superlativos.
- Bullets cuando aplica; tablas para comparaciones; código para fórmulas.
- Si no estás seguro, dilo. No alucines cifras.

REGLAS LCG
- Nunca asumas data del cliente que no esté en este Proyecto.
- Cita siempre el archivo de Project Knowledge cuando uses sus contenidos.
    03 · Estilos · Feature 02

    La voz, separada del contexto.

    Los Estilos definen cómo Claude se comunica contigo — formal, conversacional, técnico, ejecutivo. Útiles cuando alternas entre redactar para el Top Client (formal) y notas internas (conversacional).

    Estilo 01

    LCG Ejecutivo

    Formal, en español neutro, frases cortas, sin jerga AI. Usa "el cliente" no "tu cliente". Ejecutivo del Top Client lo entiende en una pasada.

    Cuándo: propuestas, slides para Top Client, minutas formales.
    Estilo 02

    LCG Trabajo

    Coloquial pero profesional, español de México, OK abreviar. Default para iteración rápida con tu Gerente o equipo.

    Cuándo: notas de trabajo, drafts, conversaciones con el equipo.
    04 · Memoria · Feature 03

    Lo que Claude recuerda entre sesiones.

    La Memoria es el conjunto de hechos persistentes sobre ti que Claude usa en cualquier conversación: tu rol, tus preferencias de formato, los clientes con los que trabajas. Activa Memoria desde la configuración de tu cuenta al inicio.

    Memoria ≠ Project Knowledge.

    Memoria son hechos sobre ti (transversales). Project Knowledge son archivos del proyecto (específicos). Lo confidencial del cliente va en Project Knowledge, no en Memoria — Memoria persiste en toda tu cuenta y se aplica a otros proyectos.

    Lo que conviene poner en Memoria como consultor LCG:

    • Tu nombre, rol, vertical principal.
    • Cómo te gustan las respuestas (formato, longitud, tono default).
    • Glosario LCG estable (PASER, MEF, Plan de Vuelo, JSA) para que no tengas que explicarlo cada vez.
    • NO: nombres de clientes activos, datos confidenciales, métricas de proyectos.
    05 · Artifacts · Feature 04

    Outputs editables.

    Los Artifacts son outputs que aparecen en un panel lateral editable — código, documentos largos, tablas, componentes HTML/SVG. Diferencia clave: puedes iterar sobre el mismo artifact sin que Claude reescriba todo cada vez.

    Tipo 01

    Documento Markdown

    Síntesis de hallazgos, draft de minuta, plantilla de Pre-Manual. Exportable a Word con formato.

    Tipo 02

    Tabla / CSV

    Lista de oportunidades cuantificadas, comparación de proveedores, mapa de stakeholders. Copy-paste a Excel.

    Tipo 03

    Código (DAX, SQL, Python)

    Fórmulas de Power BI, queries para extraer datos del ERP, scripts de procesamiento de Excels.

    Tipo 04

    HTML / SVG / React

    Mockups visuales de procesos, diagramas isométricos, prototipos de dashboards antes de pasarlos a Power BI.

    06 · Búsqueda web · Feature 05

    Cuando necesitas algo que no está en el modelo.

    Activa búsqueda web cuando preguntes por noticias recientes, regulación actualizada, benchmarks de mercado, info pública del cliente o de su industria. Claude consulta fuentes y te trae los resultados con links — siempre verifica antes de citar (regla 03).

    Cuándo NO usar búsqueda web:

    • Razonamiento sobre data interna (Claude ya la tiene si está en el Proyecto).
    • Tareas creativas o estructurales (búsqueda lo hace más lento sin valor).
    • Cuando ya tienes la fuente — pega el texto directo, no la URL.
    07 · Creación de archivos · Feature 06

    Word, Excel, PowerPoint nativos.

    Claude puede generar archivos descargables en formato Microsoft. Útil para entregables que tienen que llegar con look-and-feel oficial (no Markdown).

    .docx

    Documentos Word

    Pre-Manual, política, propuesta. Pídele estilos LCG explícitos en el prompt para que use Fraunces / Manrope si quieres branding.

    .xlsx

    Excel con fórmulas

    Plantillas de seguimiento, modelos pre-MEF, listas de KPIs con fórmulas embebidas. Mejor que copy-paste de tabla.

    .pptx

    PowerPoint estructurado

    Drafts de slides para presentación al Top Client. Útil como esqueleto — el diseño final se pulir en Plantilla LCG.

    .pdf

    PDF compilados

    Para anexos de propuesta o cierre de proyecto cuando necesitas formato no editable.

    08 · Casos LCG · cómo se ve en la práctica

    Seis flujos reales del consultor.

    Estos son flujos que verás repetir en tu primer engagement. Cada uno combina dos o tres features de Claude.ai:

    • Caso 01

      Síntesis de 12 entrevistas VSA

      Sube las transcripciones a Project Knowledge. Pídele a Claude (Sonnet) que extraiga 5 hallazgos por área, con frases textuales del entrevistado. Output: Artifact Markdown que pegas en el slide del VSA.

    • Caso 02

      Análisis de Excel operativo del cliente

      Sube el .xlsx (anonimizado o autorizado). Pídele patrones, picos, valles, comparativos por mes. Útil para identificar materialidad antes de la entrevista de validación.

    • Caso 03

      Draft de propuesta comercial

      Activa Estilo "LCG Ejecutivo" + búsqueda web. Pídele propuesta para vertical X siguiendo nuestra estructura. Salida en .docx que después se pasa a la plantilla oficial.

    • Caso 04

      Fórmulas DAX para Power BI

      Pégale el modelo de datos (nombres de tablas y columnas) y pídele las medidas que necesitas. Iteras en el Artifact hasta que pasen el syntax check.

    • Caso 05

      Pre-Manual digital de un proceso

      Estructura del proceso + reglas + capturas + checklist. Genera draft en Markdown, luego export a Word con la plantilla LCG.

    • Caso 06

      Minuta de Junta Semanal de Avance

      Pega notas de la sesión + decisiones acordadas. Salida estructurada por: avance vs. plan, decisiones, acciones (con responsable y fecha), bloqueos. Listo para enviar al equipo en 5 min.

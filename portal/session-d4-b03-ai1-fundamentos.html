    01 · Por qué Claude en LCG

    El copiloto, integrado al stack operativo.

    LCG eligió a Claude (de Anthropic) como su plataforma AI principal por tres razones: calidad de razonamiento en análisis complejo, seguridad enterprise (cumplimiento, residencia de datos) y integración nativa con M365, SharePoint, HubSpot y la plataforma interna London-bo.

    No reemplaza a ChatGPT, Copilot ni Perplexity — los complementa. Pero todo nuevo flujo AI en LCG arranca en Claude, y solo se mueve a otra herramienta cuando hay una razón clara (lo verás en AI-4 · Stack complementario).

    02 · Productos Claude vigentes

    Cinco superficies, un mismo motor.

    Los productos Claude no son cinco AIs distintas — son cinco formas de consumir el mismo modelo según el caso de uso. Conoce las cinco; uses dos o tres en tu día a día según tu rol.

    Producto 01

    Claude.ai

    El chat web y app móvil. Proyectos, Estilos, Memoria, Artifacts, búsqueda web y creación de archivos. La superficie de uso diario para 90% del equipo LCG.

    USO LCG · Todos los roles
    Producto 02

    Claude Code

    CLI para desarrollo de software. Agente que lee tu repo, edita archivos, corre tests y commitea. Usado por el equipo de Sistemas y Digital MX para construir London-bo y los activos internos.

    USO LCG · Sistemas, Digital, TD
    Producto 03

    Cowork

    Automatización de escritorio. Mueve archivos, ejecuta tareas repetitivas en tu máquina (renombrar, consolidar Excels, llenar formatos). Útil para evitar trabajo manual de bajo valor.

    USO LCG · Consultor, Analista
    Producto 04

    Claude API

    El motor crudo. Base de las integraciones propias de LCG (London-bo, Managed Agents). No la usas como consultor — pero entender que existe explica por qué algunas funciones del CRM "tienen Claude por dentro".

    USO LCG · Sistemas y Digital MX
    Producto 05

    Managed Agents

    Agentes autónomos sobre la API. Ejecutan tareas continuas (monitoreo de pipeline en HubSpot, reporte automático cada lunes). Configurados por TD, consumidos por las áreas de negocio.

    USO LCG · Configurados por TD
    03 · Modelos vigentes

    Tres modelos. Elegir bien importa.

    Claude.ai te deja elegir el modelo en cada conversación. Esa elección impacta calidad, velocidad y costo. Esta es la guía LCG para decidir cuál usar:

    Modelo
    Cuándo usarlo
    Cuándo NO
    Caso típico LCG
    Opus 4.7claude-opus-4-7
    Análisis complejo, estrategia, síntesis con muchas fuentes, problemas de razonamiento profundo.
    Tareas simples (resumen corto, parafraseo). Es overkill y más lento.
    Diseño de PreDx, síntesis del Análisis Exhaustivo, propuestas comerciales.
    Sonnet 4.6claude-sonnet-4-6
    Balance calidad/velocidad. Default para uso diario, redacción, análisis estándar.
    Cuando el problema es realmente complejo y vas a iterar varias veces — usa Opus.
    Redacción de minutas, drafts de Pre-Manuales, análisis de Excels operativos.
    Haiku 4.5claude-haiku-4-5
    Volumen alto, latencia baja. Clasificar mensajes, extraer datos de muchos PDFs, automatizaciones.
    Razonamiento profundo o piezas largas — pierde calidad.
    Procesar 200 facturas escaneadas, etiquetar tickets de HubSpot.

    Default LCG: Sonnet 4.6.

    Si no piensas activamente en qué modelo usar, deja Sonnet. Cambia a Opus solo cuando notes que Sonnet se queda corto en razonamiento (resúmenes superficiales, conclusiones genéricas). Cambia a Haiku solo cuando vas a procesar volumen alto en automatizaciones.

    04 · Reglas de oro LCG

    Cinco reglas, sin excepción.

    Claude tiene controles de seguridad enterprise pero la responsabilidad del uso es del consultor. Estas cinco reglas son la base del marco AI de LCG.

    1. Nunca pegar data confidencial del cliente sin autorización explícita

      Estados financieros, planes estratégicos, datos de empleados, clientes finales. Si tienes duda — el default es no pegar. Pregúntale al Gerente del proyecto antes.

    2. Siempre revisar el output antes de entregarlo o enviarlo

      El output de Claude es un draft, no un entregable. Tu firma va al final — y la responsabilidad técnica también.

    3. Citar fuentes cuando Claude las proporcione y verificarlas

      Cuando uses búsqueda web, abre los links y confirma que la fuente dice lo que Claude resumió. Nunca cites lo que no leíste tú.

    4. Si el output se siente "demasiado perfecto" o "demasiado específico", probablemente alucinó

      Cifras exactas que parecen mágicas, citas textuales con autor y página, datos de mercado muy puntuales — verifica antes de usar. Si no se puede verificar, no se usa.

    5. AI es copiloto. El juicio profesional es tuyo y tu responsabilidad

      Una recomendación al cliente sustentada solo en "lo dijo Claude" no es defendible. La estructura, el insight y la decisión son tuyos — Claude acelera, no reemplaza.

    05 · Academia Claude

    El portal de capacitación continua.

    Academia Claude es el activo interno de LCG para aprender Claude profundamente. Es un portal HTML independiente, mantenido por TD, con módulos por nivel de competencia, prompt library LCG y casos resueltos.

    1. Acceso

      Solicita acceso a Transformación Digital en tu primera semana. Te llega link y credencial M365.

    2. Onboarding básico (2h)

      Módulo 01 — qué es Claude, cómo se diferencia de ChatGPT/Copilot, primeros prompts.

    3. Currículo por área

      Pistas dedicadas para Operaciones, Comercial, P&C, TD. Cada una con casos LCG reales (anonimizados).

    4. Prompt Library

      Repositorio de prompts validados — síntesis VSA, draft de propuesta, análisis de minuta. Cópialos y adáptalos.

    5. Office Hours TD

      Una hora semanal en Teams. TD resuelve dudas técnicas y casos atorados — abre tu cliente y muéstrales.

    Activación esperada: al cierre de tu primera semana, deberías haber completado el módulo 01 y haber hecho al menos tres prompts de casos reales en tu primer engagement.
